## 2. The Complete End-to-End Hackathon Demonstration Arc

The MVP demonstrates a single coherent user journey proving the core value proposition:

```
Step 1: Student in Rural MP has 0 kbps internet (Airplane Mode ON).
        │
Step 2: Launches VidyaSetu MP; app opens in <400ms from local SQLite.
        │
Step 3: Plays B.A. 1st Year History Lecture (.vsmp Micro-Pack at 0 kbps).
        - Opus audio plays seamlessly.
        - Vector canvas renders Indus Valley grid plan and Great Bath.
        - Devanagari transcript auto-scrolls with clickable timestamps.
        │
Step 4: Student checks scholarship eligibility (0 kbps offline).
        - Inputs: ST, Female, Barwani District, Family Income ₹75,000.
        - Deterministic engine outputs 100% eligibility for MPTAAS Post-Matric
          and Awas Sahayata Yojana (₹22,000/year total).
        - Flags document checklist and income certificate renewal warning.
        │
Step 5: Student asks an academic doubt via voice or text in Airplane Mode.
        - Query: "हड़प्पा में कांस्य की नर्तकी की मूर्ति कहाँ मिली थी?"
        - App saves mutation in local SQLite sync_outbox.
        - UI displays: "उत्तर आउटबॉक्स में सुरक्षित है। नेटवर्क मिलते ही सत्यापन होगा।"
        │
Step 6: Student reaches a village signal point (Airplane Mode OFF).
        - Status changes to "नेटवर्क कनेक्टेड — सिंक जारी".
        - Outbox drains via Brotli-compressed batch POST in 1.2 seconds.
        - Cloud Hybrid RAG matches approved state university textbook.
        - Answer returned with verified textbook citation:
          "स्रोतः म.प्र. हिंदी ग्रंथ अकादमी, प्राचीन भारत का इतिहास, पृष्ठ 52".
```
